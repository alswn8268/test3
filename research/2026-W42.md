# 2026-W42 트렌드 — 인기 숏폼 공통점과 우리 포맷에 반영한 것

> 조사 방법: 공개된 가이드·리포트·플랫폼 정책 기사 검색 (2026-10-12).
> 대부분 업체 블로그라 **숫자는 방향만 참고**하고, 진짜 기준은 내 채널 48시간 수치(`/review`)로 정한다.
> 실제 인기 영상의 컷 속도·음량·템포는 `python -m tools.analyze_ref <영상들>` 로 직접 재서 아래 표를 갱신한다.

## 1. 인기 숏폼의 공통점 (여러 출처에서 겹치는 것만)

| 공통점 | 근거 | 우리 포맷에 반영한 것 |
|---|---|---|
| 첫 1~3초에 남을지 결정 | 여러 가이드가 같은 결론. 플랫폼별 '1.7초·2.1초·2.5초' 같은 숫자는 근거 데이터가 불분명 | 후킹 3초 장면 + 0초에 '쿵' 효과음 + 강조어 형광펜 0.35초 등장 |
| 인트로·로고 없이 바로 본론 | "첫 화면이 설명을 필요로 하면 늦다" | 워드마크는 작게 상단 고정, 첫 장면부터 핵심 숫자/질문 |
| 화면에 자막을 박아 넣기 (무음 시청) | 무음 시청이 흔해서 자막이 필수라는 주장이 반복됨 | 모든 정보가 자막으로 완결, `captions.srt` 따로 생성 |
| 1.5~2초마다 화면 변화 | 업체 플레이북의 권장값 (측정 근거 불명확, 다른 출처는 4~7초라고도 함) | 장면 2.4초 + 장면 안에서 글자·형광펜·3D·카운트업이 계속 움직임 |
| 결론을 앞에, 저장할 이유를 끝에 | 저장·공유가 추천에 유리하다는 공통 조언 | '지금 할 일' 체크리스트 + CTA 도장(저장/공유) |
| 소리 연출(효과음)로 장면 전환 강조 | 근거는 약함 (효과음 판매 업체 주장 위주) | 컷마다 휙(whoosh), 강조마다 팝, 체크마다 틱 — **A/B 로 확인할 가설** |

## 2. 배경음(BGM) — 저작권 걱정 없는 방법

- **자체 합성 BGM (기본)**: `tools/audio.py` 가 코드로 직접 작곡한다 → 남의 음원이 아니라서 저작권 문제가 없다.
  - 채널마다 스타일 고정: 월급 사용설명서 = 로파이, 칼퇴 단축키 = 업비트, 한 끗 맞춤법 = 밝은 팝
  - 편마다 조성·멜로디가 달라져 '같은 곡 반복'이 되지 않는다
  - **100BPM** 고정: 한 마디 = 2.4초 = 설명 장면 길이 → 컷이 항상 박자에 맞는다
- **외부 무료 음원**을 쓰고 싶으면 `assets/bgm/` 에 넣고 `assets/bgm/LICENSES.md` 에 출처·라이선스를 적은 뒤 `--bgm` 으로 지정.
  유튜브 오디오 보관함·픽사베이 같은 곳도 플랫폼마다 사용 조건이 달라서, 라이선스 문구를 직접 확인하고 기록한다.
- **인기 사운드**는 여전히 영상 파일에 넣지 않는다. 업로드할 때 앱에서 얹으면(볼륨 낮게) 음소거 위험 없이 트렌드를 탈 수 있다.
- 최종 음량: 약 -14 LUFS (숏폼 플랫폼에서 흔히 쓰는 기준), 최대 -1.5 dBTP 근처.

## 3. 여러 계정 운영 — 플랫폼 정책 요약 (반드시 원문 재확인)

| 플랫폼 | 알려진 내용 | 우리 규칙 |
|---|---|---|
| 유튜브 | 2025-07-15부터 '반복적 콘텐츠' 정책이 **'진정성 없는(inauthentic) 콘텐츠'** 로 바뀌고, 대량 생산·반복형 영상의 수익화를 더 엄격히 본다. AI·템플릿 사용 자체가 금지는 아니고 '독창적 가치'가 핵심 | 편마다 주제·문구·예시가 다르게, 같은 템플릿이라도 정보가 새로워야 함 |
| 인스타그램 | 남의 콘텐츠를 큰 수정 없이 재게시하는 계정은 추천에서 제외. 2026년 4월 사진·캐러셀까지 확대 | 같은 영상을 여러 계정에 올리지 않기 |
| 틱톡 | 규칙 위반을 피하려고 여러 계정을 쓰는 것, 정지된 계정의 행동을 다른 계정으로 이어가는 것 금지 (2023 가이드라인 개편 보도) | 계정마다 주제 분리, 서로 맞팔·좋아요 품앗이 같은 조작 금지 |

**정리**: 주제별로 다른 계정을 운영하는 것 자체는 흔한 방식이지만,
① 같은 영상을 여러 계정에 올리기 ② 계정끼리 참여 부풀리기 ③ 표면만 바꾼 대량 업로드는 피한다.
그래서 이 저장소는 **채널마다 주제·색·음악·말투·해시태그를 완전히 분리**하고, 업로드는 사람이 직접 누른다.

## 4. 이번 주 새 채널 (주제를 고른 이유)

1. **칼퇴 단축키** (엑셀·윈도우)
   - 기존 타깃(20~30대 직장인)과 같아서 계정 간 서로 소개하기 쉽다.
   - 사실 확인이 쉽다 (마이크로소프트 공식 도움말).
   - '저장'을 부르는 실용 콘텐츠이고, 소재가 수백 개라 매일 올려도 고갈되지 않는다.
2. **한 끗 맞춤법** (회사·카톡 맞춤법)
   - 퀴즈형(틀림/맞음)이라 첫 3초 후킹이 쉽고 '공유'가 잘 일어나는 형식이다.
   - 국립국어원이라는 명확한 공식 출처가 있다.
   - 세금처럼 매년 바뀌는 정보가 아니라 오래 쓸 수 있다.

## 4-1. 호기심(어그로형) 채널 추가 — 참고 화면 분석

사용자가 공유한 3D 호기심 채널 화면(10편 썸네일·제목·조회수)을 보고 정리한 것. 조회수가 적고 올린 시점이 달라 **경향만** 본다.

| 관찰 | 예 (참고 채널 제목 형식) | 우리 채널에 반영 |
|---|---|---|
| 제목이 '당신'에게 말을 건다 | "지금 당신 코의 한쪽은 ~", "~은 당신 탓이 아닙니다" | 후킹 공식 '당신·지금', '무죄' |
| 일상 물건·몸의 '왜?' | 이어폰 줄, 빨간불, QR 모서리, 옷 태그 | 기둥: 내 몸 · 생활 속 물건 · 자연·우주 |
| '만약'형 가정 | "전 인류가 ~하면?" | 후킹 공식 '만약' |
| 화면 한가운데 큰 3D 물체 + 자막 1~2단어 강조(노랑) | 3D 인물·물체, 노란 강조 | 노랑 신호색, 물음표·전구 3D 소품, 장면당 강조 1개 |
| 도장·라벨로 결론 | "무죄 NOT GUILTY" 도장, 규정 라벨 | 우리 CTA 도장, '판정' 비교 장면 |
| 조회수 1~2천 = 몸·위험·규칙 / 한 자릿수 = 최근 올린 편 | — | 올린 지 오래되지 않은 편은 비교 불가 → 48시간 지표로만 판단 |

참고 채널과 **같은 주제는 피했다** (코·하품·이어폰·QR 등은 쓰지 않음). 같은 장르 안에서 다른 소재로 간다:
딸기/베리, 빨대 구멍, 8분 전 햇빛, 비행기 둥근 창문, 쭈글해지는 손가락.

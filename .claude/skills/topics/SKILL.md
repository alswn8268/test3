# /topics — 주제 선정

입력: `research/<이번주>.md`, `backlog.md`, `learnings.md`, `metrics.csv`(있으면 `python -m tools.review`).

1. 후보를 모은다: 리서치 주제 후보 + backlog 미사용 항목 + 지난주 '후속편 후보'(같은 후킹, 다른 주제).
2. 각 후보에 점수를 매긴다 (각 1~3점): 관심도(검색·트렌드) · 경쟁 낮음 · 시의성(마감일) · 출처 확보 쉬움.
3. 비율을 지킨다: **시즌 2편 + 상시 3편**. 상시 기둥 5개(카드·통장·연금저축·월세자취·청년혜택) 중
   이번 달 강조 기둥을 우선한다 (README 의 12개월 달력 참고).
4. `topics/<주차>.md` 에 표로 쓴다: 순위 · 주제 · 시리즈 태그 · 점수 · 후킹 문장 초안 · 예정 편 번호 · 업로드 요일.
   업로드 요일은 CLAUDE.md 의 시간표를 따른다.
5. **최종 5개는 사람에게 묻는다** (AskUserQuestion 이 있으면 사용). 확정되면 표에 ✅ 표시하고,
   고르지 않은 후보는 `backlog.md` 에 한 줄씩 추가한다.
6. 확정된 주제마다 `/script` 실행을 안내한다.

# /analyze — 참고 영상 분석

1. `refs/` 에 영상이 있는지 확인. 없으면 사람에게 요청: 앱에서 잘 된 영상(같은 주제 채널 3~10개)을 화면 녹화나 저장으로 받아
   `refs/` 에 두기. **분석 전용**이고 재업로드·편집 소스로 쓰지 않는다. refs/ 는 git 에 올라가지 않는다.
2. `python -m tools.analyze_ref refs/*.mp4 --out research/refs-<주차>.md`
   (길이 · 컷 수 · 컷 간격 중앙값 · 첫 3초 컷 · 첫 컷 시점 · 음량 LUFS · BPM 어림값)
3. 결과를 우리 포맷(30초, 장면 2.4초, 100BPM, -14 LUFS)과 비교해 **바꿔볼 점 하나만** 고른다.
   BPM 은 효과음이 많은 영상에서 어림값이 흔들린다는 점을 같이 적는다.
4. 화면 구성(첫 장면에 무엇이 나오는지, 자막 위치·크기)은 대표 영상 2~3개의 프레임을 뽑아 직접 본다:
   `ffmpeg -ss 0.5 -i refs/<파일> -frames:v 1 out/ref.png`
5. 제안은 `research/<주차>.md` 의 '참고 영상 수치' 칸에 붙이고, 실제 변경은 한 채널에서 A/B 로 먼저 시험한다.

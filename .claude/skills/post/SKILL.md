# /post — 업로드 문구

1. 초안: `python -m tools.post <ep> --month <다시 볼 달> --tags <넓은1> <넓은2> <주제1> <주제2>`
   - 넓은 태그 예: 연말정산, 직장인, 재테크, 사회초년생 / 주제 태그는 영상 핵심어
2. `post.md` 를 다듬는다:
   - 첫 줄 = 후킹 문장 그대로(초안에 들어 있음), 둘째 줄 = '저장해두고 ○월에 다시 보기'
   - 본문 2~3줄: 핵심 숫자 1개 + 지금 할 일 1개. 출처가 factcheck.md 에 없는 숫자는 쓰지 않는다.
   - 해시태그 정확히 5개 (`#TODO` 남기지 않기), 마지막은 `#월급사용설명서`
3. 예약 표에 날짜·시간을 채운다 (`topics/<주차>.md` 의 편성 요일 + CLAUDE.md 시간표).
   틱톡 예약은 수정이 안 되니 문구를 확정한 뒤 걸라고 적어 둔다.
4. **업로드·예약은 하지 않는다.** 사람이 Meta Business Suite / TikTok Studio / YouTube Studio 에서 직접 누른다.

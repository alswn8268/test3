# /post <채널> <편> — 업로드 문구

1. `python -m tools.factcheck <채널> <편> --check` 가 통과하지 않았으면 멈춘다 (초안 영상은 올리지 않는다).
2. 초안: `python -m tools.post <채널> <편> --month <다시 볼 달> --tags <넓은1> <넓은2> <주제1> <주제2>`
   - 넓은 태그는 `channel.json` 의 broad_tags 에서, 주제 태그는 영상 핵심어. 채널 태그는 자동으로 붙는다.
3. 플랫폼별로 다듬기 (post.md 에 세 구역이 있음):
   - **틱톡**: 후킹 + 저장 이유 + 해시태그 5개. 예약 후 수정이 안 되니 확정 후 예약.
   - **유튜브 쇼츠**: 제목은 짧게(영상 제목 그대로 또는 질문형), 설명 첫 줄에 후킹, 해시태그 3개 이내. `captions.srt` 를 자막으로 올리면 검색에 도움.
   - **인스타 릴스**: 후킹 + 저장 이유 + 본문 2~3줄 + 해시태그 5개. 커버는 `preview/s01.png`.
   - 셋 다 **`final.mp4` 원본 파일**을 올린다. 틱톡에서 받은 워터마크 영상을 다른 곳에 올리면 추천에서 밀릴 수 있다.
4. 예약 표: 이 채널 `schedule` 의 요일·시간. 같은 주제 계정의 세 플랫폼에는 같은 영상, **다른 주제 계정에는 절대 같은 영상 금지**.
5. **업로드·예약은 하지 않는다.** 사람이 각 플랫폼 공식 도구(Meta Business Suite / TikTok Studio / YouTube Studio)에서 직접 누른다.

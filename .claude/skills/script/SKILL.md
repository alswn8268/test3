# /script — 대본 쓰기

1. 편 폴더 준비: 인자가 새 주제면 `python -m tools.new_episode "<제목>" --series "<시즌 · …|상시 · …>" --slug <영문>`
   으로 빈 대본을 만든다. 이미 폴더가 있으면 그 `script.json` 을 고친다.
2. 기존 편(`episodes/ep01/script.json`)을 예시로 읽고 같은 톤·구조를 따른다. 규칙은 CLAUDE.md '대본 구조'.
   - 장면 1 `hook`: 손해·숫자로 3초 안에 멈추게. 예) "연봉의 [25%] / 이 숫자 모르면 / 카드 공제 {0원}"
   - 장면 2~10: 정보 3개, 라벨 `01  …` `02  …` `03  …`. 숫자는 `number`, 둘 비교는 `compare`.
   - 장면 11 `check`: '지금 할 일' 3개 (오늘 바로 할 수 있는 행동)
   - 장면 12 `cta`: 저장 이유(언제 다시 볼지) 또는 공유 대상(부모님·친구) + 팔로우
3. 숫자를 쓸 때는 지금 확인 가능한 공식 출처가 있는 것만 쓴다. 출처 후보 URL 을 대화에 같이 적어 둔다.
4. `python -m tools.validate <ep>` → 오류 0 될 때까지 고친다. 경고(9글자 초과)는 줄을 나눠 해결한다.
5. 사람에게 `say` 말투를 다듬을 기회를 준다 (전체 내레이션을 한 번에 보여주기). 다음은 `/factcheck <ep>`.

# /script <채널> <편|주제> — 대본 쓰기

1. 새 주제면 `python -m tools.new_episode <채널> "<제목>" --series "<시리즈 태그>" --slug <영문>` 으로 빈 대본 생성.
2. **같은 채널의 기존 편**을 예시로 읽고 `channel.json` 의 voice(말투)·concept 를 따른다. 규칙은 CLAUDE.md '대본 구조'.
   - 장면 1 `hook`: 손해·숫자·퀴즈로 3초 안에 멈추게
   - 장면 2~10: 정보 3개 (라벨 `01  …` `02  …` `03  …`)
     - 금액·비율 → `number`, 둘 비교·틀림/맞음 → `compare`, 단축키 → `keys`
   - 장면 11 `check`: 지금 할 일 / 오늘 고칠 것 3개
   - 장면 12 `cta`: 저장할 이유 또는 공유 대상 + 팔로우
3. 후킹은 CLAUDE.md '후킹 공식'과 `channel.json` 의 `hook_rules` 를 따른다. 어그로는 호기심으로만 —
   논란·공포·낚시 금지, 후킹에서 던진 질문의 답은 영상 안에서 반드시 준다. 가설이면 '아직 논쟁 중'이라고 말한다.
4. 공식 출처로 확인 가능한 내용만 쓴다. 확인 못 한 숫자·기능은 빼고, 출처 후보 URL 을 대화에 같이 적는다.
5. 같은 채널의 다른 편과 후킹 문장·예시가 겹치지 않게 한다 (반복 콘텐츠로 보이지 않게).
6. `python -m tools.validate <채널> <편>` 오류 0. 경고(9글자 초과)는 줄을 나눠 해결.
7. 사람에게 `say` 전체를 보여주고 말투를 다듬게 한다. 다음은 `/factcheck <채널> <편>`.

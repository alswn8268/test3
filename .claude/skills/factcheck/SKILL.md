# /factcheck — 사실 확인

금융 채널에서 틀린 숫자 하나가 채널 신뢰를 깎는다. 이 단계는 건너뛰지 않는다.

1. `python -m tools.factcheck <ep>` — 숫자가 들어간 화면 문구를 표로 뽑는다 (이미 적힌 출처·확인 표시는 보존).
2. 표의 각 줄마다 WebSearch/WebFetch 로 **공식 출처**를 찾는다:
   국세청(nts.go.kr)·홈택스, 국가법령정보센터(law.go.kr), 기획재정부, 고향사랑e음, 금융감독원 등.
   - 귀속연도·시행일이 맞는지 확인 (작년 기준 숫자를 올해 것처럼 쓰지 않기)
   - 계산 결과(예: 900만 × 16.5% = 148.5만)는 직접 다시 계산하고, 출처 칸에 근거 규정 링크를 적는다
   - 행동 안내(예: '오늘부터 체크카드')처럼 숫자가 규정이 아닌 줄은 근거가 되는 규정 링크를 적는다
3. 출처 칸에 URL, 확인 칸은 **비워 둔 채** `☐` 로 둔다. Claude 는 ✅ 를 직접 찍지 않는다.
   원문과 다르면 `❌ 원문: …` 으로 적고 대본 수정안을 제시한다.
4. 사람에게 링크 목록을 보여주고 원문을 눈으로 확인한 줄만 ✅ 로 바꾸게 한다 (사람 판단 단계).
5. 대본을 고쳤으면 `python -m tools.factcheck <ep>` 로 표를 갱신하고, 끝으로
   `python -m tools.factcheck <ep> --check` 통과를 확인한 뒤 `/render <ep>` 를 안내한다.
